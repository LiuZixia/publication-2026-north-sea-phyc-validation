# Agent Tracking Archive

This directory stores immutable UTC snapshots of the root `PROGRESS.md` and `PENDING.md` files.

At the start of each substantive lead-agent session and at each genuine project milestone, copy the current live pair here before refreshing them. Use:

- `YYYYMMDDTHHMMSSZ_PROGRESS.md`
- `YYYYMMDDTHHMMSSZ_PENDING.md`

Never edit or replace a snapshot after creation. Use a numeric suffix if two snapshots would otherwise have the same name. Archive files are version-controlled project records; they must contain no credentials or restricted data.
